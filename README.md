# voluntech-frontend

Páginas desenvolvidas em Angular para o sistema de voluntariado.

Este projeto foi gerado com [Angular CLI](https://github.com/angular/angular-cli).

## Comandos Principais

* **ng serve**: Roda o projeto localmente em `http://localhost:4200/`
* **ng generate component nome**: Cria um novo componente standalone
* **ng build**: Gera a pasta `dist/` para deploy
